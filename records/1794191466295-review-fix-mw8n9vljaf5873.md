# AuthCore review fix round 1

## done

- `AuthCore` (Godot, `client/godot/core/auth_core/`): when `release` or `clear_dev_values` ends a storage wait, `_storage_call` now returns `null`, not a `FAILED` outcome. Every caller then returns its failure value with no further work and no log. A storage adapter that returns no outcome counts as `FAILED` in `_run_storage`, so `null` only means a wait was ended
- Commit e5dbcc41. Its message gives the cause and evidence for the earlier rule changes e6caa1ef and ad967246 (R1-3)
- Last `ogw core test godot` for AuthCore and its dependents (AdCore BootstrapCore PaymentCore PushCore QACore RealtimeCore RemoteConfigCore TutorialCore UnitTestCore): pass, also with `--web`. `ogw code check core`: pass for all four checks
- No engine-specific implementation rules document was written, and `## <engine> build` of `tools/ogw.md` was not written
