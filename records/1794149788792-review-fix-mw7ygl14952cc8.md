# review fix BootstrapCore round 2

## done

- `client/godot/core/web/ogw-shell.html`: `preloadLaunchValues` now returns `Promise.resolve([])` before it reads the query parameter when `window.ogwDevExport !== true`. So a page of an STG or PROD export (no `html/head_include` marker) ignores `ogw_launch_values`: it reads no file, adds no `--launch-values=` user argument, and starts the engine as a page without the parameter (`open-game-works-core/skills/client-core/engines/godot.md:121`). The function and its constant sit between the comments `// ogw:launch-values begin` and `// ogw:launch-values end`, so the browser-run test can take the shell code from the page it runs in
- New core test `client/godot/core/bootstrap_core/tests/test_web_shell_launch_values.gd` (browser run only; a native run records it as a skip through `UnitTestCore.require_platform`):
  - `test_page_of_the_browser_run_is_a_dev_export`: the DEV export page of the browser run has `window.ogwDevExport === true`
  - `test_export_without_the_marker_ignores_the_launch_value_parameter`: takes the shell's `preloadLaunchValues` from the served page and runs it on a page with no marker, with marker `false` and with marker the text `"true"`, using `ogw_launch_values` set to `x` (not a URL path), `/missing.json` (HTTP 404) and `/values.json` (HTTP 200). Every case resolves with no user argument, no fetch and no preloaded file
  - `test_dev_export_reads_the_launch_value_parameter`: with marker `true`, an existing file adds `--launch-values=/tmp/ogw_launch_values.json` and preloads it, a missing file rejects with the HTTP 404 message, a value that is not a URL path rejects without a fetch, and no parameter gives no argument
- Reproduction: with the guard removed, `test_export_without_the_marker_ignores_the_launch_value_parameter` fails (the cases reject or add `--launch-values=`, as the finding describes). With the guard in place it passes
- Last runs on the committed HEAD: `ogw core test godot "BootstrapCore QACore UnitTestCore" --web` pass, `ogw core test godot "BootstrapCore QACore UnitTestCore"` pass (the modules of `ogw core dependents BootstrapCore`). `ogw code check core`: type check, lint, dependency, secret all pass
