# review fix storage round 1

## done

- `server/core/storage/tests/abort.test.ts`: three new PostgreSQL tests of the `read_db` retry (`server/core/storage/db/pg_worker.ts:427-433`), plus helpers `read_pid` and `end_reads`. `end_reads` runs in a session on another thread while this thread waits in its synchronous query. It ends each session that waits for the `testing.hold_db` holder, one at a time, and then ends the holder so its lock is freed. In each test, a `read_db` query waits on `LOCK TABLE test_counter IN ACCESS EXCLUSIVE MODE`.
  - The read connection was open before the query and is ended during it: the query returns its rows from a new backend pid, which is the read connection after that.
  - The run on the new connection is also ended: the query throws a value that is not a `StorageMisuse`, and the next `read_db` query succeeds on a new pid.
  - The idle read connection is ended and the worker sees the close, so the query opens a new connection, which is then ended during the query: the query throws, with no second run.
- No implementation change. No engine-specific implementation rules document was written, and `## <engine> build` of `tools/ogw.md` was not written.
- Checked against the defect: with the retry branch removed (the error always thrown), the first test fails ("the server closed the connection"). With the `opened_before` guard removed, the third test fails. Both were restored before the commit.
- `ogw core test server` with storage and every server module that `ogw core dependents storage` lists: all pass. `ogw code check core`: all checks pass.
