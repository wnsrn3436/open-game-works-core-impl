# review fix TweenCore round 2

## done

- TweenCore (Godot): the DEV finite skip now ends skipped tweens in their own "skip end of a frame", separate from the `end_due` flush that zero-cycle tweens use. Each skipped request gets a request number (`TweenRecord.skip_seq`). `_skip_end` (client/godot/core/tween_core/tween_core.gd:613) remembers the process frame it started in and the last request number, and ends only the skipped tweens numbered up to that number. A skipped tween requested after the skip end of its frame started (in a completion callback, in code resuming after `wait_end`, or later in that frame) sets `_skip_waiting` (tween_core.gd:592). The frame processing of the core node in the next frame then queues that frame's skip end (tween_core.gd:640), so a chain moves one step per frame and the frame ends. Skipped tweens are not advanced by frame processing (tween_core.gd:652). `release` resets the new state
- Core tests: client/godot/core/tween_core/tests/test_finite_skip.gd:170 and :184
- Last `ogw core test`: godot and godot `--web`, run on TweenCore and on every module listed by `ogw core dependents TweenCore`, all pass, after the commit. `ogw code check core`: type check, lint, dependency and secret all pass
- No engine-specific implementation rules document was written. `## <engine> build` of `tools/ogw.md` was not written

Added tests: test_finite_skip.gd:170 `test_completion_callback_that_plays_a_finite_tween_again_gets_one_completed_per_frame` and :184 `test_loop_that_plays_a_finite_tween_and_waits_for_its_wait_end_gets_one_completed_per_frame`. Each test runs a chain of 5 and checks that consecutive `Completed` ends are exactly 1 process frame apart, and that the first one is in the frame of the request. With tween_core.gd swapped back to HEAD before this fix, both tests failed with a frame difference of 0 for ends 1–4. With the fix, they pass
