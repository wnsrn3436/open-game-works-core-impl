# update core: AccessibilityCore

## done

- `AccessibilityCore` (Godot), `client/godot/core/accessibility_core/accessibility_core.gd`
  - `list_text_scales(buffer: PackedInt32Array) -> int`: fills the buffer from index 0 with `AccessibilityCore.textScales` in ascending order (the list is sorted once in `init`) and returns the number filled. It does not change the buffer size. A buffer shorter than the list gets its first values and one error log. Before `init` it returns 0 with an error log
  - `reset_settings() -> void`: sets every option to the default `AccessibilitySettings`, applies only the options whose value changed (so a DEV test text scale stays when the text scale option was already 1000, and is replaced when it changes), removes the 5 `device` keys of `## data` with `LocalDataCore.remove_value`, and publishes `AccessibilityChangedEvent` once when any value changed and none otherwise. Before `init` it logs an error
  - `init` fails with an error log when `AccessibilityCore.textScales` has more than 8 elements
  - `dev/accessibility_core_dev.gd`: doc comment of `set_test_text_scale` now names `reset_settings` (no behavior change)
- tests
  - `tests/test_text_scale.gd`: `list_text_scales` with [1500, 1000, 1250] fills 1000, 1250, 1500 and returns 3 and `set_text_scale` of each is `true`; 8 values fill a buffer of 8 without a log; a short buffer fills its size with one error and a long buffer changes only the filled values
  - `tests/test_lifecycle.gd`: `list_text_scales` and `reset_settings` before `init` log an error and `list_text_scales` returns 0 with the buffer untouched; 9 text scales make `init` fail with one error
  - `tests/test_reset_settings.gd` (new): after `set_text_scale`(1250), `set_color_mode`(`Deuteranopia`), `set_subtitles` of the non-default value, `set_reduce_shake`(`true`), `set_reduce_flash`(`true`), `reset_settings` publishes one event, `get_settings` is the default, `LocalizationCore.get_text_scale` is 1000, the filter is hidden, the shake offsets of each frame equal those with reduce shake off, a flash of maximum opacity 1 reaches 1, the device file has none of the keys, defaults come back after `release`, `init`, `apply_saved_settings`, and a second `reset_settings` publishes none; a reset with no changed value publishes none and still removes a saved key; with `subtitlesDefault` `false` and subtitles on, `reset_settings` hides the visible subtitle in that frame; the test text scale cases of `## test`
  - `tests/test_render_color_filter.gd`: after `reset_settings`, a pure red pixel filtered by `Deuteranopia` is red again
- core tests: `ogw core test godot AccessibilityCore BootstrapCore QACore UnitTestCore` pass, and the same with `--web` pass (the modules of `ogw core dependents AccessibilityCore`; it lists no server module). `ogw code check core` pass (type check, lint, dependency, secret)
- No other module's code changed. The benchmark game does not use `AccessibilityCore`, so it needed no change
- No engine-specific implementation rules document and no `## <engine> build` of `tools/ogw.md` written
