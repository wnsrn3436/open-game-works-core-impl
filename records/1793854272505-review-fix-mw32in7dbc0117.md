# review fix UnitTestCore round 3

## done

- UnitTestCore (Godot): `require_platform` returns `bool` (whether the test goes on). It gives `false` when the `_check` fails, in a regression test, outside a test, and when the platform of the run is not in the list (which records skip); otherwise it gives `true`. `_record` checks failures (assert failures, `fail_reasons`, GUT fail count) before `skip_reason`. `_finish_test` returns the failure reasons even when `skip_reason` is set
- Callers of `require_platform` in `client/godot/core/unit_test_core/tests/test_page_input.gd` use the return value and no longer have their own platform guards
- `client/godot/core/game_update_core/tests/test_web_downloader.gd`: the three web-only tests return right after `require_platform` gives `false` (the round-3 `## out of scope` item). Before this change the skip hid their failures in native runs; with R3-1 fixed, those tests would fail there
- `ogw core test godot UnitTestCore GameUpdateCore` and `ogw core test godot --web UnitTestCore GameUpdateCore`: all pass. `ogw core dependents UnitTestCore` lists only UnitTestCore. `ogw code check core`: type check, lint, dependency and secret all pass
- No engine-specific implementation rules document was written. `## <engine> build` of `tools/ogw.md` was not written

## spec proposals

none

## review

- R3-1: fixed. `client/godot/core/unit_test_core/dev/unit_test_core.gd:478` (the failure check comes before skip) and `:677` (failure reasons are returned whether or not the test was skipped). Tests: in `test_require_platform_skips_a_core_test_and_fails_a_regression_test` (`client/godot/core/unit_test_core/tests/test_run.gd:329`), `test_requires_another_platform_then_fails` is now `fail`, and its message holds the assert failure and the unchecked error log that come after the call. The new sample `test_fails_then_requires_another_platform` (`tests/resources/sample_platform.gd`) checks that an assert failure before the call also gives `fail`
- R3-2: fixed. `client/godot/core/unit_test_core/tests/test_run.gd:317-345` now expects `fail` for a failure after the skip. Through the sample's static `returned` record, it also checks the return value in three cases: `false` for a list without the current platform, `true` for a list with it, and `false` for every case in a regression run. In `sample_platform.gd`, `test_requires_another_platform` returns right after `false`, and the body after that point fails if it runs
- R2-1: fixed. `client/godot/core/unit_test_core/dev/unit_test_core.gd:1531`: `require_platform -> bool`, and every early return gives `false`. The callers that guard on the return value are `sample_platform.gd`, `test_page_input.gd:44` and `:61`, and `game_update_core/tests/test_web_downloader.gd`. These tests are checked by the same `test_run.gd` test (the return-value asserts) and by the test_page_input and web-downloader runs in both the native run and the browser run
- D1: fixed by the R2-1 fix
