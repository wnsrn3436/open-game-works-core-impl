## spec proposals

- `BootstrapCore` ban body: the spec says the public code is passed "in two groups of 4 characters joined with `-`" but does not say what is passed for a public code that is not 8 characters (the empty public code a server of an earlier core version can give, per `storage` `get_user_record`). The implementation passes a text that is not 8 characters unchanged, so the empty public code stays the empty string. Proposal: write that an empty public code is passed as the empty string
