# update core: CameraCore

## done

- `client/godot/core/camera_core/camera_core.gd`: `init` seeds the shake noise with `TimeCore.make_random_seed("camera_shake")` (new constant `_SHAKE_SEED_PURPOSE`), in place of `TimeCore.get_device_time() ^ TimeCore.get_monotonic_time()`. This follows the `UtilCore` `### random` rule on main. So a dev run with a random base (`TimeCore.set_random_base`) gets the same shake noise, and the same flash check frames, on every run. Without a random base the seed still comes from the device time through `TimeCore`. `CameraCoreDev.set_shake_seed` and all other behaviour are unchanged
- `client/godot/core/camera_core/tests/test_shake.gd`: two new tests
  - `test_init_seeds_the_noise_with_the_camera_shake_random_seed_of_time_core`: with random base 42, the first two noise values and the next draw match `UtilCore.create_random(UtilCore.make_purpose_seed("camera_shake", 42))`. After `release` and another `CameraCore.init`, the noise comes from `make_purpose_seed("camera_shake", 43)` (the next k of the purpose)
  - `test_shake_without_set_shake_seed_follows_the_random_base_of_the_run`: with random base 7 and no `set_shake_seed`, the offsets of 20 frames of `shake(1.0)` equal those after `set_shake_seed(make_purpose_seed("camera_shake", 7))`
- camera-core.md has no spec change, so no other `## test` item is new or changed. The two tests cover the seeding change
- No other module's code was changed. Content-facing behaviour of every operation is unchanged
- Core tests (last runs, on commit d38bb046): `ogw core test godot CameraCore` pass, `ogw core test godot CameraCore --web` pass, `ogw core test godot AccessibilityCore BootstrapCore CameraCore CutsceneCore QACore UnitTestCore` pass, the same with `--web` pass (these are the modules that `ogw core dependents CameraCore` lists)
- `ogw code check core`: type check, lint, dependency and secret all pass
- No engine-specific implementation rules document was written. `## <engine> build` of `tools/ogw.md` was not written
