# update core: SoundCore

## done

- `SoundCore.reset_volume_settings` (`client/godot/core/sound_core/sound_core.gd`): sets the volume of every bus to 1, mute to `false` and haptics on to `true`, applies each bus to the engine at once through `_apply_bus` (that keeps DEV mute, so a bus with DEV mute on stays silent), and deletes the 11 keys of `## data` from the `device` file with `LocalDataCore.remove_value`. DEV mute is not changed
- The `sound_variant` and `sound_variation` random seeds in `SoundCore.init` now come from `TimeCore.make_random_seed(purpose)` and no longer from `UtilCore.make_purpose_seed(purpose, TimeCore.get_device_time())`. The `debug` seed logs stay as they were
- Tests:
  - `tests/test_volume.gd` `test_reset_volume_settings_gives_defaults_at_once_removes_the_keys_and_keeps_dev_mute` covers the spec `## test` item for `reset_volume_settings`: it checks the defaults, the 0 dB levels of `Bgm`, `Sfx` and `Master` in the same frame, that no key of `## data` is left in the `device` file, the same values after `release`, `init` and `load_volume_settings`, and that a bus with DEV mute on stays silent
  - `tests/test_variation.gd` `test_variant_and_variation_randoms_are_seeded_by_time_core_make_random_seed`: with `TimeCoreDev.set_random_base(42)`, both random instances draw the same sequence as `make_purpose_seed(<purpose>, 42)`
- `ogw core test godot` and `ogw core test godot --web` both pass, run on SoundCore and every module that `ogw core dependents SoundCore` lists (26 client modules, no server modules). The last run of each passes on commit 1bf3b46c. `ogw code check core` passes (type check, lint, dependency, secret)
- No other module's code was changed. No caller of another module needed a change. No engine-specific implementation rules document, and no `## <engine> build` of `tools/ogw.md`, was written
