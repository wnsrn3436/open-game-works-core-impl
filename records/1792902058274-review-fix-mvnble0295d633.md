# review fix LocalizationCore round 1

## done

- `LocalizationCore` (Godot): `_apply_fonts` now saves the heading font item of a heading type only when the type has that item of its own (`get_font_list(type).has(item)`, through the new `_has_own_font`), not when `has_font` is true only because the theme has a default font. `_restore_heading_types` sets the saved item back only for a type that had one, and clears the item `load_fonts` added to a type that did not have it. An own item that holds no font (for which `get_font` gives `default_font`) is saved as `null` and restored as an item that holds no font
