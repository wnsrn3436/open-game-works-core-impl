# core agent report: UICore review fix round 1

## done

- UICore (Godot): `scroll_by` of the system popup content (`client/godot/core/ui_core/system_popup_view.gd:144`) now returns `true` and moves the scroll position only when the body and extra text do not fit in the scroll area (max scroll position of the vertical scroll bar above 0). So `UICore._on_input` keeps an up or down input as a scroll consumption only when the body area scrolls, and over a body that fits the input goes on to the world stage of `InputCore`.
- Added test `test_key_direction_that_starts_the_focus_mode_over_a_body_that_fits_is_not_consumed` (`client/godot/core/ui_core/tests/test_system_popup.gd`).
- No engine-specific implementation rules document written; `## <engine> build` of `tools/ogw.md` not written.
- Core tests: `ogw core test godot` and `ogw core test godot --web` with UICore and the modules of `ogw core dependents UICore`: all pass on web; native all pass except AccessibilityCore, NativeUiCore, QACore, VirtualPadCore `skipped` (render pass not run: macOS screen locked or display asleep). `ogw code check core`: all checks pass.
