# update core: remove the DEV operations and states the specs no longer have (Godot client core)

## done

Modules changed (Godot client core), following harness commits 182a362 and 0758642:

- `QACore`
  - Removed the built-in commands `set_network_delay`, `set_feedback_off` and `set_reward_presentation_off`: their `list_commands` rows and handlers in `client/godot/core/qa_core/dev/qa_builtins.gd`.
  - Removed the feedback switch from `client/godot/core/qa_core/dev/qa_core.gd`: the feedback off and reward presentation off switches, the reward window and its check at frame start, the reward moment calls from `mark` (`Goal`, `Reward`) and from `ItemChangedEvent`, the module state table and the calls it made (`SoundCoreDev.set_dev_mute`, `set_play_skip`, `CameraCoreDev.set_shake_skip`, `ScreenEffectCoreDev.set_world_skip`, `PoolCoreDev.set_effect_skip`, `TweenCoreDev.set_finite_skip`), the `CameraCore.stop_shake` call when feedback off turned on, and the release step that turned the switches off.
  - Removed the `get_state` field `frame_step_fps` (`client/godot/core/qa_core/dev/qa_query.gd`).
  - Removed the core settings key `QACore.rewardPresentationWindowMs`: its setting read and lower-bound check in `qa_core.gd`, the value in `settings/core-settings.json` (with `ogw settings unset core`), and the property and `required` entry in `settings/core-settings.schema.json`. `ogw core spec` and `ogw core test` regenerated `core-spec/QACore.json`, `server/core/testing/dev/setting_types.ts`, `server/generated/core_settings_schema.json` and `client/godot/generated/core_settings.json` / `core_settings_types.json`.
- `SoundCore`: removed `SoundCoreDev.set_dev_mute` and DEV mute (the per-bus state, its part in the bus mute, and the skipped `SoundPlayedEvent`), and `SoundCoreDev.set_play_skip` and play skip.
- `CameraCore`: removed `CameraCoreDev.set_shake_skip` and shake skip.
- `ScreenEffectCore`: removed `ScreenEffectCoreDev.set_world_skip` and World skip (the skipped-handle path of `fade`, `flash` and `play_preset`).
- `PoolCore`: removed `PoolCoreDev.set_effect_skip`, effect skip and its deferred take-back before the frame is drawn. `PoolCoreDev` had no other operation, so `client/godot/core/pool_core/dev/` was deleted. `_lend` publishes `EffectSpawnedEvent` for each auto-return borrow again, as it did before.
- `TweenCore`: removed `TweenCoreDev.set_finite_skip` and finite skip (the skip end and its queue, the record fields `finite_skip`, `skip_due`, `skip_seq`). `TweenCoreDev` had no other operation, so `client/godot/core/tween_core/dev/` was deleted. `tween_core.gd`, `tween_record.gd` and `tests/test_lifecycle.gd` are back to their content before 049dad61, the commit that added finite skip. The commits after it on these files changed only finite skip.
- `NetworkCore`: removed `NetworkCoreDev.force_delay`, together with what only it used: `_forced_delay_ms`, the DEV received hook `_dev_received_hook`, and the waiter field `deliver_at` and its checks in `_on_frame` and `_run_due`.
- `TimeCore`: no code change. `get_frame_step_fps` stays as a core test seam.

Core tests:
- Deleted: `qa_core/tests/test_feedback_switch.gd`, `sound_core/tests/test_dev_feedback.gd`, `screen_effect_core/tests/test_world_skip.gd`, `pool_core/tests/test_effect_skip.gd`, `tween_core/tests/test_finite_skip.gd` (and their `.uid` files).
- Removed:
  - QACore `test_set_network_delay_delays_the_responses_until_0` and the three `frame_step_fps` tests
  - CameraCore `test_shake_skip_adds_no_trauma_and_no_event_while_the_trauma_there_decays`
  - the parts of NetworkCore `test_force_failure_and_force_delay` that tested the delay. It is renamed `test_force_failure` and now checks that `force_failure(-1)` lets a request through.
- Adjusted:
  - the QACore built-in command `args` table
  - the `extra_limit_ms` example: `set_network_delay 700` became `set_server_time_offset 700`
  - the expected warn and error counts that included the removed calls (QACore `test_time_scale_and_network_setups`, ScreenEffectCore lifecycle)
  - the lifecycle initial-state checks of CameraCore, NetworkCore and TweenCore
  - SoundCore `test_reset_volume_settings_...`, which no longer has the DEV mute clause (0758642)

Other callers in `open-game-works-core-impl/`: `git grep` finds no call of the removed operations or key outside `records/` (the benchmark game, tools and server included).
