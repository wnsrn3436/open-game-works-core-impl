# review fix TweenCore round 3

## done

- TweenCore (Godot): the skip end (`_skip_end`, client/godot/core/tween_core/tween_core.gd:627) ends a skipped tween whose target object or value receiver was destroyed while it waited with `TargetDestroyed` (no end state applied, receiver not called, no log) instead of `Completed`. `_on_frame` keeps leaving `skip_due` records to the skip end, so they do not progress
- Three core tests in client/godot/core/tween_core/tests/test_finite_skip.gd (R3-1, R3-2, R3-3)
- No engine-specific implementation rules document written; `## godot build` of `tools/ogw.md` not written

none

## review

- R3-1: fixed. Test `test_completion_callback_that_plays_two_finite_tweens_ends_both_in_the_next_frame` (test_finite_skip.gd:220): a completion callback plays finite tweens `a` (the freed lowest slot) and `b` (a higher slot), and both must end in the next frame. Mutation `if record.skip_due:` at tween_core.gd:626 makes it fail with `{ "first": 44, "b": 44, "a": 45 }`
- R3-2: fixed. Test `test_skipped_tween_waiting_for_the_next_frame_does_not_progress_while_the_clock_moves` (test_finite_skip.gd:250): a completion callback plays a skipped `play_value` FLOAT 10→20 over 100 ms and moves the test clock by 50 ms; the receiver must get only `[20.0]` and `wait_end` `Completed`. Mutation `if record.end_due:` at tween_core.gd:653 makes it fail with `[15.0, 15.0, 20.0]`
- R3-3: fixed at tween_core.gd:627 (`TargetDestroyed` when `_is_gone(record)`). Test `test_skipped_tween_whose_target_is_destroyed_while_it_waits_ends_with_target_destroyed` (test_finite_skip.gd:280): a completion callback plays a skipped `move` on node X and a skipped `play_value` on a receiver node, then `queue_free`s both; the callback and both `wait_end`s must get `TargetDestroyed`, the receiver must not be called, and no error log. With the old `_end(slot, TweenEndReason.COMPLETED)` it fails with `[1]` / `{0: 1, 1: 1}`
